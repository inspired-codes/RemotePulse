Ready to deploy across your LAN?

Run our non-interactive installer on your Windows and Linux nodes. The worker handles service registration, firewall negotiation, and secure credential storage automatically.

Install worker and connect your host in under 30 seconds:

PS > irm https://psrun.inspired.codes/get-worker.ps1 | iex
🪟 Windows (x64 .zip) SHA-256: loading… 🐧 Linux (x64 .zip) SHA-256: loading…
ℹ️
Prerequisites & Engine: Requires .NET 10 (the bootstrap installer automatically checks and prompts to install it if missing). PowerShell CLI is not required at runtime — RemotePulse Worker embeds its own internal PowerShell 7.6 execution engine.
▶️
What happens next: the script downloads the Worker for your OS, verifies its SHA-256, and installs it as a background service (asking for admin rights). Your browser then opens http://localhost:7923/ with a pairing QR code — scan it with the RemotePulse app on your phone (this site’s /app page) and the machine is paired. To update later, run the same command again; your pairing is kept.
🔏
Open source & verifiable builds: RemotePulse is open source under AGPL-3.0 on GitHub. The Worker zips served here are the attested GitHub Release builds — check any download yourself.
🗑️
Uninstall: download the zip for your OS from the Manual (Zip) tab, extract it, and run Uninstaller.ps1 as admin (Linux: sudo pwsh ./Uninstaller.ps1). It removes the service and files, and asks whether to keep your pairing keys.
